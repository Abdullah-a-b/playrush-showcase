# PlayRush 🎮

منصة ألعاب جماعية لحظية (Real-time) بواجهة عربية أولاً — تحدَّ أصدقاءك أو لاعبين عشوائيين من
حول العالم في مجموعة ألعاب معلومات وذكاء، عبر الويب أو تطبيق أندرويد.

🔗 **جرّب اللعبة الآن**: [playrush.pages.dev](https://playrush.pages.dev)

---

## الألعاب

| اللعبة | الوصف |
|---|---|
| 🔤 **خلية الحروف** | لعبة سيطرة استراتيجية على لوحة سداسية — أجب صح لتسيطر على الخلية. |
| ⚽ **مسيرة لاعب** | خمّن اسم لاعب كرة قدم من خلال الأندية التي لعب لها بالترتيب. |
| 🏦 **بنك** | سلسلة إجابات متتالية — احفظ رصيدك بـ"بنك" قبل أن تخطئ وتخسر كل شيء. |
| 🎭 **من أنا** | خمّن الشخصية من تلميحات متتالية. |
| 🧠 **معلومات عامة** | أسئلة معلومات عامة كلاسيكية بنظام تنافسي. |

كل لعبة تدعم مباريات أونلاين حقيقية (عامة أو خاصة مع الأصدقاء)، ووضعاً فردياً ضد بوت بعدة
مستويات صعوبة.

## المزايا

- مباريات لحظية عبر Socket.IO — لا تأخير محسوس.
- نظام حسابات كامل (تسجيل عادي أو عبر جوجل)، تصنيف/Elo، محفظة وعملات داخل اللعبة.
- نظام أصدقاء، دردشة داخل المباراة، وإبلاغ عن اللاعبين.
- تطبيق أندرويد أصلي (نفس تجربة الويب مُعبّأة عبر Capacitor).
- محتوى يتجدّد تلقائياً (أسئلة/لاعبون جدد تُستورد دورياً من مصادر مفتوحة).

## التقنية (نظرة عامة)

بُنيت المنصة بـ **FastAPI + Socket.IO** للباك اند، و**HTML/CSS/JS** ثابت بدون إطار عمل للفرونت
اند، مع **PostgreSQL** لقاعدة البيانات و**Capacitor** لتغليف تطبيق الجوال.

> هذا المستودع مخصّص للعرض فقط — الكود المصدري الكامل يُدار بشكل خاص.
